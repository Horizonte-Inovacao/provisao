# Case 3D — PróVisão V1.5

Modelos da carcaça que protege a eletrônica na aba da viseira. **Em desenvolvimento**, os requisitos completos (REQ-M01 a M10) estão no plano de ação do grupo; os três inegociáveis:

1. **Abertura livre na frente dos sensores** — o VL53L0X não mede através de plástico;
2. **Compartimento da bateria** sem nada comprimindo a célula pouch, com acesso externo à porta de carga;
3. **Motores pressionados contra as têmporas** por almofada — vibração sem contato firme não é sentida.

Material: PETG no corpo (PLA deforma no calor do nosso sol), interface com a pele em EVA/TPU.

## Estrutura

- `cad/` — arquivos fonte (FreeCAD/Fusion + STEP exportado). O fonte sempre acompanha o STL: repositório de hardware aberto sem CAD editável não é aberto de verdade.
- `stl/` — malhas prontas para fatiar. O GitHub renderiza STL em 3D direto no navegador.
