# Registro das nossas decisões

Toda vez que tomamos uma decisão que muda o rumo do projeto, escrevemos um registro curto aqui. Cada registro conta o problema que tínhamos, o que escolhemos e o que ganhamos e perdemos com a escolha.

Fazemos isso por dois motivos. Primeiro, para quem chegar depois entender por que o projeto é como é, sem precisar perguntar. Segundo, para nós mesmos: daqui a seis meses é fácil esquecer por que descartamos uma ideia que parece boa.
